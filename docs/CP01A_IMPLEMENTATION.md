# CP01A — Visual Pilot (implementation)

## Implemented
- Godot 4 project with procedural scene creation from scripts (all game objects persist between mode changes).
- 4 pixel sprite sheets with 4 idle frames and 6 walk frames, handcrafted with transparent backgrounds.
- Parallel sky / clouds / mountain / forest / meadow / foreground with independent scroll factors.
- Borderless compact mode, pin-on-top toggle, draggable top bar, expanded mode, playback pause.
- Hand-authored art regenerated by `python tools/generate_assets.py` (Pillow) so the art can evolve without destructive edits.

## Differences / limitations
- This is **not yet** final art or gameplay. First art pass for approval against Reel. Sprites are original fan-art, not frame extractions.
- No monster, combat, stage logic, loot or saves yet: the scene is only CP01A, not a fake CP02 implementation.
- Window-position persistence, touchscreen input, high-DPI / multi-monitor quirks still need native QA.
- Godot editor execution is required for runtime confirmation on Windows; static files and Python art-generation checks do not replace this.

## Controls
F5 in Godot; `Tab` compact/expanded; `Space` move/pause; `1` artist focus; `2` party; `H` HUD toggle; `T` pin window; top-bar drag in compact mode.

## Acceptance
1. The four silhouettes are recognisable at the compact scale.
2. Background layer colors, composition and pixels read like the provided Reel.
3. TAB changes window mode without restarting animation/camera state.
4. No anti-aliasing on the sprites; there is no source-video material packaged with the app.
5. Creator signs off on the art, or sends concrete adjustments before CP01B.
